🚀 QUICK START (3 Steps)

  Step 1: Test it locally
    > npm run dev
    
    Then open http://localhost:9000 in your browser
    (Press Ctrl+C to stop the server)

  Step 2: Customize your information
    - Edit src/components/HeroSection.vue (your name & title)
    - Edit src/components/AboutSection.vue (your bio)
    - Edit src/components/SkillsSection.vue (your skills)
    - Edit src/components/ProjectsSection.vue (your projects)
    - Edit src/components/ContactSection.vue (your contact info)
    
    See QUICKSTART.md for detailed instructions!

  Step 3: Build and deploy
    > npm run build
    
    Then upload all files from dist/spa/ to your cPanel!

🌐 DEPLOYMENT

  After running "npm run build":
  
  1. Open your cPanel File Manager
  2. Go to public_html/ (or your subdirectory)
  3. Upload ALL files from dist/spa/ folder
  4. Visit your domain - your portfolio is live! 🎊

  See DEPLOY.md for detailed instructions and troubleshooting.
